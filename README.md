# TropaTT CRM Language Pack — العربية

TropaTT CRM Arabic localization package. Includes pack-specific supplemental web translations.

A language pack module for the [TropaTT](https://github.com/Anton-Barinov/TropaTT) self-hosted CRM and work platform.

## Installation

### Method 1: TropaTT Marketplace (Recommended)

1. In your TropaTT CRM, go to **Admin → Languages → Marketplace**.
2. Search for **العربية** (`crm.language-pack-ar-sa`).
3. Click **Install**.

### Method 2: Manual ZIP Upload

1. Download `crm.language-pack-ar-sa-1.0.2.zip` from the [Releases](https://github.com/Anton-Barinov/tropatt-language-pack-ar-sa/releases) tab.
2. In TropaTT CRM, navigate to **Admin → Languages**.
3. Click **Install from file** and upload the downloaded ZIP.
4. Activate the language in your language settings.
